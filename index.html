Recent work includes Go2W–OpenArm KALO early-launch assistance, a lift-equipped mobile manipulator for shelf transfer, and CEBO-based stair-climbing wheel design optimization. 휠-레그 모바일 매니퓰레이션과 AMR 시스템에서 안정성 중심 학습·평가 문제를 다룹니다. 최근에는 Go2W–OpenArm 기반 KALO early-launch assistance, shelf-transfer용 lift-equipped mobile manipulator, CEBO 기반 계단 등반 휠 설계 최적화를 수행했습니다.

KALO: Kangaroo-LocoManipulation

Implemented a launch-assist strategy for a Go2W–OpenArm platform by using the manipulator as a constrained inertial appendage during early acceleration. Built the Isaac Lab/RSL-RL evaluation setup and compared Base, Fixed carrying-pose, and KALO controllers in a launch-onset-aligned 0–1.5 s window. Go2W–OpenArm 플랫폼에서 manipulator를 초기 가속 구간의 제한된 inertial appendage로 쓰는 KALO launch-assist strategy를 구현했습니다. Isaac Lab/RSL-RL 평가 환경을 구성하고 Base, Fixed carrying pose, KALO를 launch-onset aligned 0–1.5 s window에서 비교했습니다.

Role
Concept, platform setup, evaluation metrics, Isaac Lab experiments개념 제안, 플랫폼 셋업, 평가 지표 설계, Isaac Lab 실험
Tools
Isaac Lab, RSL-RL, PyTorch, Go2W–OpenArm
Result
Normalized forward-velocity AUC(0–1.5 s) +15.1% (0.726 → 0.835); t90 1.703 s → 1.067 s; 90%-target-speed episodes within 1.5 s 29/128 → 69/128Fixed 대비 normalized forward-velocity AUC(0–1.5 s) 15.1% 증가(0.726 → 0.835); t90 1.703 s → 1.067 s; 1.5 s 내 90% target speed 도달 episode 29/128 → 69/128
Paper

2025-2026Revised manuscript resubmitted

CEBO-Based Stair-Climbing Wheel Design

Formulated a six-variable T-pedal wheel design problem for stair-climbing performance and pitch stability. Automated CoppeliaSim evaluations and applied CEBO after validating it on 2D–12D benchmark functions. 계단 등반 성능과 pitch stability를 대상으로 한 6변수 T-pedal wheel 설계 문제를 정의했습니다. CoppeliaSim 평가 루프를 자동화하고, 2D–12D benchmark 검증 후 CEBO를 실제 wheel-design case에 적용했습니다.

Role
T-pedal wheel search-space design, CEBO optimization experiments, CoppeliaSim evaluation-loop automationT-pedal wheel 탐색공간 설계, CEBO 최적화 실험, CoppeliaSim 평가 루프 자동화
Tools
Bayesian Optimization, CoppeliaSim, Python
Result
Nominal traversal time -23.31% (9.405 s → 7.213 s); body-pitch stability median -37.84% (1.102 deg → 0.685 deg) under the nominal friction conditionNominal friction 조건에서 traversal time 23.31% 감소(9.405 s → 7.213 s), body-pitch stability median 37.84% 감소(1.102 deg → 0.685 deg)
Paper
