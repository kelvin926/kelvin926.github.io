# Hyunseo Jang Academic Homepage

Source for [home.hyunseo.kr](https://home.hyunseo.kr/), built with [Jekyll](https://jekyllrb.com/) and [al-folio](https://github.com/alshedivat/al-folio).

## Local Preview

Docker is the preferred local setup on Windows:

```powershell
docker compose up
```

Then open:

```text
http://localhost:8080
```

## Content

- Profile: `_pages/about.md`
- Publications: `_bibliography/papers.bib`
- Projects: `_projects/`
- Social links: `_data/socials.yml`
- Site settings: `_config.yml`
