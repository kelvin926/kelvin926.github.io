# Public-content rules

This repository is public.

- Never copy, summarize, or publish material from private repositories, draft theses, unreleased experiments, or other non-public sources here.
- A request to consult a source or identify a photograph does not authorize publication of that source or image.
- Use assets and facts that were already intentionally public before the task. Verify their public source and provenance before adding them.
- An accidentally published file or immutable commit URL is not an approved public source.
- Treat branches, pull-request diffs and descriptions, CI output, image URLs, and commit history as public publication surfaces.
- Do not put private source paths, private links, unpublished results, or non-public media into this repository or its pull requests.
